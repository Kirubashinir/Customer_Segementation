# Customer_Segementation
📌 Project Overview

This project performs Customer Segmentation using Machine Learning Clustering Algorithms. The goal is to group customers based on their purchasing behavior and income patterns so businesses can create targeted marketing strategies.

The project uses:

K-Means Clustering
Hierarchical Clustering
Data Visualization
Customer Behavior Analysis

Dataset: Mall Customers Dataset

🎯 Objectives
Analyze customer demographics and spending behavior.
Identify distinct customer groups.
Apply K-Means clustering for segmentation.
Apply Hierarchical Clustering for comparison.
Visualize customer segments.
Generate actionable business insights.

Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-Learn
SciPy
